# MHW Anim Tools v1.1.0

- Added **Build Evaluated Helper** for duplicate-track animation playback and retargeting.
- Added **REST** and **ACTION** base options for missing animation channels.
- Added APIs for source-bank caching, single-action export and editing individual source tracks.
- Reduced repeated parsing and serialization in the baking APIs.
- Fixed reimporting an animation clearing an existing Action with the same name.
- Fixed duplicate-track preservation checks overlooking edits to earlier tracks.
- Export now stops when raw duplicate-track components are missing.
- Blocked direct LMT export of evaluated helper Actions.
