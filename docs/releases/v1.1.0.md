# MHW Anim Tools v1.1.0

Repeated LMT records can now drive a separate evaluated source armature in
Blender using the confirmed native skeletal binding rule. Raw source records
remain available for authoring and preservation.

## Changes

- **Build Evaluated Helper** in the LMT Inspector resolves the last applicable
  source record per destination, including aliases and more than two records.
  It preserves native timing and quaternion interpolation at subframes, with
  an explicit rest or complete action base for missing components.
- **Incomplete raw duplicate channels block export.** Direct writes also
  reject export analyses containing errors. Reimports create distinct Actions
  instead of clearing a same-named Action, and preservation checks compare
  individual duplicate slots.
- Source snapshot and encoded-slot APIs provide exact unchanged round trips
  or explicit per-slot edits with complete readback audits and rebased TIML.
- CPU throughput APIs reduce repeated parsing, serialization, hashing and
  deep-copy comparisons. The four-clip G8F/Lara benchmark measured **50.030 s
  baseline versus 37.730 s integrated** across three-run medians: **24.6% less
  complete-operation time**, with identical reference outputs. This gain
  requires the documented caller changes; updating the add-on alone does not
  enable that integration.

## Compatibility and limits

- Supported on **Blender 4.5 LTS**, tested on **4.5.10**. The main model workflow
  uses armatures imported through **Blender MHW Model Editor**.
- **CPU-only runtime; no NVIDIA, CUDA, PyTorch or research-tool dependency.**
- Native helpers are source snapshots for preview/retargeting. They cannot be
  exported over original raw slots through normal LMT export. Rebuild them
  after changing the source or base. Legacy authoring codecs and the existing
  retargeting solver keep their behavior.
- Mirroring/joint remapping, specialized control consumers and complete
  cinematic layering/IK remain unsupported. The Eorzea arm discrepancy of
  approximately **1.62–1.74 degrees RMS** is still unresolved.

## Validation

- **318 unit tests** pass under Python 3.10 and Blender's Python 3.11.
- **2,583 native binding comparisons** match across all **773 duplicate-bearing
  actions plus 88 ordinary controls**. Binding selection is verified separately
  from downstream context; **149 mirrored entries** remain blocked for sampling.
- **14 Blender fixtures** pass quarter-frame sampling, exact source round trips,
  explicit edited-slot audits and deterministic TIML relocation. Synthetic
  helpers also pass save/reopen, template isolation and export guards.
- A fresh complete-operation regression preserves exact reference LMTs and
  motion arrays. Full measurements and limits are in the linked reports below.

## Install or update

Download **mhw_anim_tools-v1.1.0.zip** from this release and use Blender's
**Install from Disk**. Do not manually install GitHub's Source code archive.

Existing users can use **Preferences > Add-ons > MHW Anim Tools > Check for
Updates > Install Update**, then restart Blender or reload scripts. Automatic
checks follow the configured interval. The existing updater consumes this
release's tag archive and retains the installed add-on folder name.

See [installation](../installation.md), [supported rules](../repeated-track-support.md),
[native helper integration](../duplicate-track-baking-integration.md), and
[throughput integration and measurements](../bake-throughput.md). Publication
does not modify production baking scripts or game packages.
